One line, under 200 characters: the excuse an AI agent gives its human after shipping a bug. Pure Node stdlib — `main.ts` writes the line to `/output/entry.txt`.

> Sorry, I shipped the bug because I ran the tests, they passed, and I believed them — turns out my tests were written by me too.

## Run it

```sh
node main.ts
```
